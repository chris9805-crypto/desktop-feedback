Support

IronBlock runs entirely on your device, with no account behind it. That makes most problems something you can fix yourself in under a minute — and makes backups the one thing worth being disciplined about.

Before you train

This app is not medical advice. It is a training log that suggests loads and set counts from numbers you have entered yourself. It knows nothing about your health, your injuries, your medication or your history.

Talk to a doctor before starting a training programme, particularly if you are new to lifting, returning from injury or illness, pregnant, or managing any medical condition. Stop and get advice if something hurts in a way that is not ordinary training discomfort. The numbers on the screen are a suggestion from a formula, not an instruction, and you are the one holding the weight — if a prescription looks wrong for how you feel today, it is wrong. Change it.

Putting it on your phone

iPhone and iPad

  1. Open the app in Safari (it must be Safari — Chrome on iOS cannot install it)
  2. Tap the Share button, then Add to Home Screen
  3. Open it from the home-screen icon from then on

This is not just a shortcut. Installed, it runs full screen, works with no signal, and — importantly — its stored data is treated as something worth keeping. Left as an ordinary Safari tab, iOS can clear the storage after about a week of not opening it.

Android

Chrome usually offers Install app on its own. If not: menu (⋮) → Install app or Add to Home screen.

Backups, and moving to a new phone

There is no cloud copy. A backup is a file you keep.

  1. Settings → Save a backup file — you get a dated .json
  2. Put it somewhere that is not just this phone: email it to yourself, drop it in cloud storage, anywhere
  3. On the new device, install the app, then Settings → Restore from a file and pick it. It tells you what is in the file before it overwrites anything

The app will nag you about this once about five sessions have built up unsaved, or one has sat unsaved for three weeks. The nag is the feature — please do not train it away.

Something went wrong

My training has disappeared

Check first that you are opening it the same way you logged it: the home-screen app and a Safari tab can hold separate storage, and so do two different browsers. If you have a backup file, Settings → Restore from a file. If you have not, the log is genuinely gone — there is no server copy to recover, which is the cost of there being no server at all.

It will not install, or the install option is missing

On iOS the page must be open in Safari and loaded over https. In a private window, Add to Home Screen is unavailable.

It says storage is unavailable

Private browsing, or a browser set to block site data. The app keeps working for the session but will not remember anything after you close it. Use a normal window.

The rest timer stops when I switch apps

Known, and a real limitation of a web app: a backgrounded browser tab gets suspended, so the countdown does not run reliably and will not notify you. Keep the screen on during rest, or watch the clock.

The weights it suggests look wrong

The engine works from what you logged, so one mis-keyed set can skew the next session. Progress → find the session → correct it, or tap why? on a set card to see exactly what the suggestion was based on. Nothing is locked: change the weight on the card and the app follows you.

Reporting a bug or asking for something

Open an issue on GitHub. Say what you tapped, what you expected and what happened — and which phone and browser, because most of the awkward ones are specific to a device.

Please do not paste your backup file into an issue: it is your whole training log and the issue tracker is public.

Privacy

Nothing is collected, because there is nowhere to collect it to. The full policy is one page and says so in more detail.
